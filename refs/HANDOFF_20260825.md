## 2. OPEN DEFECT: live prices are not reaching the app

Reported from his device: the Trade list shows **NVDA $1,184.00 +3.1%**, letter-tile logos.

**Those are the seed values.** `src/lib/stocks.ts:21` hardcodes `price: '$1,184.00', chg: 3.1`, and
every number in his screenshot matches that table exactly. So the app is not showing stale live
data — it is showing **no** live data and falling through `priceOf()` to the seed.

**The API is healthy.** Verified by direct request this session:
```
/api/market?action=quote&sym=NVDA  -> {"price":208.48,"changePct":-3.27}
/api/market?action=marks           -> 12526 marks, date 2026-08-24
/api/market?action=logo&sym=NVDA   -> a real JPEG
```

**The mechanism is documented in the code already.** `src/lib/api.ts` `apiBase()`:

> "THIS IS THE C98 FAILURE, MADE LOUD. On native, `hostUri` exists only while Metro is attached, so
> a production or TestFlight build with no `EXPO_PUBLIC_API_URL` resolves its base to `''` and every
> fetch goes to a relative path with nothing to resolve against. Atlas, market data and options all
> die at once — and NONE of it reproduces in development."

### What is PROVEN vs what is NOT

**Proven:** in the simulator the seed prices reproduce exactly, because `.env.local` had no
`EXPO_PUBLIC_API_URL`, so `apiBase()` fell through to `hostUri` = Metro, which does not serve
`/api/*`. `safe()` swallows the failure and `priceOf()` returns the seed.

**NOT proven, and this matters:** whether the same thing is true in **production**.
`EXPO_PUBLIC_API_URL=https://euphoria-native.expo.app` **is** present in the EAS production
environment — I listed it. `EXPO_PUBLIC_*` is inlined at bundle time and the OTA was published with
`--environment production`, so in principle it should be baked in. His screenshot is evidence
something is wrong anyway. **Do not "fix" this until you have determined which.** The cheapest
decisive test: get him to open Trade on device with the perf overlay on, or add a one-line
diagnostic that renders `apiBase()` on screen and screenshot it from TestFlight.

### Local change you must know about
I appended `EXPO_PUBLIC_API_URL=https://euphoria-native.expo.app` to **`.env.local`** so dev can
reach the real API. It is **gitignored, local only, not committed**. Metro inlines env at startup,
so **Metro must be restarted** for it to take effect — it had not been when this session ended, so
the simulator was still showing seed prices.
